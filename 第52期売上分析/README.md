# 第52期 売上分析（2025年8月 vs 2026年8月 単価・数量寄与分解）

「第51期見込と第52期計画について_20260827（部門長回覧用）」に、8月実績（2508・2608タカハシ包装売上全明細）の
単価・数量寄与分析と、商品群別・営業所別の単月推移スライドを追加したもの。

- `scripts/analyze.py` : 売上明細を商品群・営業所に突合し、ラスパイレス価格指数で単価効果・数量効果に分解（`2608_単価数量分解結果.json` を出力）
- `scripts/build.py`   : 回覧用pptxに 8/27版（v5）の商品群別・営業所別スライドを構造コピー
- `scripts/build2.py`  : グラフを4〜8月に更新、8月要因分解まとめスライドを追加、ページ番号を通し番号化
- `scripts/finalize.py`: ロゴ画像を縮小してファイルサイズを圧縮
- 成果物: `第51期見込と第52期計画について_20260905（部門長会議用）.pptx` / `.pdf`

担当者コード→営業所の対応は「第51期下期○○営業所担当者別実績.xlsx」（水産部は部門別実績）の集計行から取得。
商品分類コード→商品群の対応は「商品群_新旧対応表_20260822.xlsx」。
