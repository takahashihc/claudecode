高橋将史商会 食品包装業界 ホルムズ海峡・中東情勢 週次レポートを生成します。

## 実行手順

以下のステップを順番に実行してください。

### Step 1: ニュース収集（WebSearch × 8クエリ）

以下の8つのトピックをWebSearchで検索し、各結果を日本語で要約してください：

1. `ホルムズ海峡 通行状況 封鎖 2026`
2. `イラン アメリカ 紛争 石油化学 ナフサ 2026`
3. `原油 ブレント ナフサ 価格 2026年`
4. `ポリエチレン ポリプロピレン ポリスチレン 価格 供給 2026`
5. `ニトリル手袋 供給不足 価格 2026`
6. `食品包装 材料 供給 価格 2026`
7. `円ドル 為替レート 2026年`
8. `段ボール 発泡スチロール 食品トレー 価格 仕入 2026`

### Step 3: レポート生成スクリプトを実行

```bash
mkdir -p /home/user/claudecode/reports/YYYY-MM-DD
python3 /home/user/claudecode/run_report.py --json /home/user/claudecode/reports/YYYY-MM-DD/news_YYYY-MM-DD.json --date YYYY-MM-DD
```

### Step 4: 生成確認とコミット・プッシュ

生成されたファイルを確認し、GitHubにプッシュしてください：
