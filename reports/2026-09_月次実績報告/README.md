## 作成上の注意点
- 境港の計画値は外部リンク数式（[1]包装資材6月まで計画）のため、externalLink のキャッシュ値で復元して集計（scripts/patch_ext.py）。8月の既存値を全件再現できることを確認済み。
- 水産部ファイルの「合計」行（6〜9セクション）が境港水産部合計ではなく JF境の行を参照しており、0038境その他（9月 14.7千円）が漏れるため修正（scripts/fix_suisan.py）。
- 4〜8月の実績は 2609担当者別売上粗利益実績（最新データ）で全て差し替え（松江0032/0033/0034、広域0552 7月粗利、水産部0010/0017 4月など）。
  営業所別ファイルの7.実績、営業会議資料の下期累計、第51期9月実績の BACKDATA4〜8月（実績列）、年計表の2026/4〜8 当月 に反映。差替内容は excel/差替・注意箇所_flags.json と scripts/nenkei_update_log.txt。
- 第51期9月実績の BACKDATA4月 水産部「荷役」は 0104大田荷役＋0106浜田荷役 の最新値（7,893.8）に差し替え（従来値 5,509.0 とは定義が異なる可能性あり）。境港 機械 4月・6月も最新の機械データで差し替え。
- 【参考】大海分は8月以降空欄。0061瓦田部長は各営業所に含めない（従来どおり）。
