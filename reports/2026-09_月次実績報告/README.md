## 作成上の注意点
- 境港の計画値は外部リンク数式（[1]包装資材6月まで計画）のため、externalLink のキャッシュ値で復元して集計（scripts/patch_ext.py）。8月の既存値を全件再現できることを確認済み。
- 水産部ファイルの「合計」行（6〜9セクション）が境港水産部合計ではなく JF境の行を参照しており、0038境その他（9月 14.7千円）が漏れるため修正（scripts/fix_suisan.py）。
- 最新データでは8月粗利が 松江0033 ▲2.3千円・境港0909 ▲0.4千円 修正されているが、8月資料の確定値をそのまま保持。
- 【参考】大海分は8月以降空欄。0061瓦田部長は各営業所に含めない（従来どおり）。
