## スクリプト実行順
`scripts/compute.py` → `compute2.py` → `build.py`（PPTX）、`gen_excel.py` → `gen_excel2.py`（Excel）。パスはスクリプト冒頭の `S` を環境に合わせる。

## 担当者別実績ファイルの数式補修（`scripts/fix_office.py`）
7月版から引き継いだ数式の欠け・誤参照を補修した（8月更新とは独立の修正）。
- 合計列（K=SUM(E:J)、R=SUM(L:Q)）が無い担当者行に数式を追加：松江 機械/包装資材の原田、下関の自治体(0028)、水産部の境その他(0038)
- 計画比・前期比セクションの粗利益率列で参照行がずれていた数式を修正：松江（全体/包装資材 X列・U〜X列）、境港（全体 T〜V列、機械/包装資材 V〜X列）
- 水産部の機械/包装資材シートは元の設計（差額行の粗利率をIFで算出）を維持

## 広域営業部 0552 の担当者変更
0552 は高橋氏の退職により馬場部長（東京）へ担当変更（コードは変わらず）。営業会議資料・広域営業部ファイルの 0552 行を「馬場部長（東京）」、0550 行を「馬場所長（東京）」（システム上の名称）に改称し、営業会議資料の【参考】馬場部長合計（94〜96行）に 0552 の行を加算するよう数式を修正（J94 の固定値も数式化）。
