## LINE 側の設定手順

1. https://developers.line.biz/ に LINEアカウントでログインし、プロバイダーを作成（例: タカハシ包装センター）。
2. 「Messaging API」チャネルを作成（チャネル名例: 漁獲速報Bot）。
3. 「Messaging API設定」タブ
   - Webhook URL に上記URLを設定し、「Webhookの利用」をオン。「検証」を押して成功を確認。
   - 「応答メッセージ」「あいさつメッセージ」をオフ（LINE Official Account Manager 側の設定）。
   - 「グループ・複数人トークへの参加を許可する」をオン。
4. 「チャネル基本設定」からチャネルシークレット、「Messaging API設定」から長期アクセストークンを発行し、Supabase の Secrets に登録。
5. Bot（QRコード）を友だち追加し、「競り市案内」グループに招待する。
6. 招待後に `line_catch_reports` に `event_type = 'join'` の行が入れば受信成功。

## 投稿手順（Claude が実行）

```sql
select line_timestamp, user_name, message_type, text, signed_url
from public.line_catch_reports
where message_type in ('image','text','file')
  and line_timestamp >= now() - interval '1 hour'
order by line_timestamp desc;
```

1. 上記で直近1時間の大田分を取得し、画像は署名付きURLから読み取る。
2. Gmail で `subject:境港漁獲日報 newer_than:1h` を検索し、添付を読み取る。
3. 産地ごとに魚種・数量を箇条書きにまとめ、Slack `#漁獲速報`（C0C1A842340）へ投稿する。
4. どちらも見つからなければ、その旨を報告する（投稿しない）。
